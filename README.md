# ÉLAN - Fashion Store Frontend

A responsive e-commerce storefront built with plain HTML5 and CSS3 (no JavaScript).

## Features
- Sticky header with brand, navigation and search / bag icons
- Promotional hero banner with a pulsing sale sticker
- 12 product cards in Clothing, Footwear and Accessories sections
- CSS Grid layout, 4 columns on desktop, 2 on tablet and mobile, 1 on very small phones
- Absolute-positioned sale / new badges, wishlist hearts and "Add to Bag" overlays
- Hover effects: card lift, image zoom, sliding overlay
- Automatic dark / light theme using `prefers-color-scheme`

## Project structure
```
index.html
css/
  base.css        colours, reset, typography
  header.css      top bar, navigation, icons
  hero.css        hero banner
  products.css    grid, cards, badges, hover effects
  footer.css      footer and newsletter form
  responsive.css  tablet and mobile layout
```

## Run locally
Open `index.html` in a browser.
